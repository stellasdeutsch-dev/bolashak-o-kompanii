# Блок «О компании» как история: 15 вариантов

Прототипы блока «О компании» с сайта bolashak.gov.kz, рассказанного прокруткой вниз в четыре шага. Отдельно от основного сайта.

- Страница: https://stellasdeutsch-dev.github.io/bolashak-o-kompanii/
- Тексты блока — с bolashak.gov.kz, слово в слово; цвета, шрифт Roboto, иллюстрации и фото — с тестовой копии сайта.
- Анимации на GSAP 3.13 + ScrollTrigger (`assets/`), общий движок `assets/story.js`. При настройке «уменьшить движение» и без скриптов шаги стоят друг под другом.
- Пересобрать страницы: `node --experimental-strip-types build.mjs` (рядом должна лежать папка `site/` проекта Bolashak-way: оттуда берутся иллюстрации).
- Макеты тех же 15 вариантов — в Figma, страница «О компании · варианты слайдов».
